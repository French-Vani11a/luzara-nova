# Keep CLAUDE.md up to date

Whenever you make a change that affects anything documented in `CLAUDE.md`, update `CLAUDE.md` in the same task, before you finish.

Update it when you:
- add, rename, move or delete a file or folder listed under Structure
- add or change an API route, middleware, or env variable
- change npm scripts, ports, or how to run the project
- change a convention (stack, error format, data flow)
- complete or add a "Before going live" item (for example, remove the preview button)

Rules:
- Edit the affected line only; keep the file short and factual.
- Do not add details that can be read straight from the code.
- If nothing in `CLAUDE.md` is affected, leave it alone.
- Mention in your final reply that you updated it.
